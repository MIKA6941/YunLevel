## 2. 信号定义（只留这些）

| 位号 | 含义 | 角色 |
|------|------|------|
| **TI1104** | 换热器出口温度 ℃ | 主被控量 PV |
| **FI1105** | 介质出口通道流量 kg/s（FV1105 后） | 负荷 / 串级副环对象 |
| **FI1102** | 冷却水流量 kg/s | 显示 / 串级副环对象 |
| **FV1102** | 冷却水阀 % | 主操纵量（温度回路） |
| **FV1105** | 介质出口阀 % | 操纵量（流量回路） |

热源/燃料：不进 UI，作**教师可配扰动** `d_hot(t)`。

## 3. 工艺与控制

```text
  [热源扰动 d_hot ▼]
         │
         ▼
  ┌──────────────┐      出口通道
  │  E1102      │ ──►  FI1105 ── FV1105 ──►
  │  锅炉换热器 │ ──►  TI1104
  └──────────────┘
         ▲
    FI1102 ◄── FV1102（冷却水）
```

### 推荐回路

| 档 | 接线 | 说明 |
|----|------|------|
| 默认 | **TI1104 → FV1102** | 出口温度定值 |
| 串级 A | TI1104 → **FI1102** → FV1102 | 温度 / 冷却水流量 |
| 串级 B | TI1104 → **FI1105** → FV1105 | 温度 / 出口流量 |

**可选对象限制**（下拉只出现）：

- PV：TI1104、FI1105、FI1102  
- MV：FV1102、FV1105  
- 副环：FI1102 或 FI1105（与 MV 匹配）

作用方向：冷却水阀开大出口温度降 → **反作用**；出口阀开大流量升 → **正作用**（流量环）。

## 4. 物理（参考 temo-1.0）

| 项 | 做法 |
|----|------|
| 换热 | LMTD：`Q_hx = k_hx × LMTD` |
| 传热系数 | `k_hx ∝ (mw)^0.8 × (ms)^0.6` 简化 |
| 能量 | `C·dT/dt = ms·Cs·(T_in−T) − Q_hx − 壁损` |
| 冷却水 | 与 `mw`、FV1102 开度相关 |
| FI1105 | 出口通道流量，受 FV1105 控制（二阶/变率） |
| TI1104 | 测量滞后 + 可选噪声 |
| 热源 | `d_hot` 教师可配（阶跃/斜坡/随机） |
| 燃料 | 不改写入口温度；仅可留调试死变量 |

**TI1103 入口温度**：可作常数或慢变，不作为教学主变量。
