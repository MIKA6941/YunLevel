## C. 仿真图：布局问题（重点）

### C1 根因（与代码一一对应）

| # | 位置 | 现状 | 后果 |
|---|------|------|------|
| 1 | `.process-visual` | `align-items: center` | 泵/阀/**管**/罐整行竖向**中线对齐** |
| 2 | `.pipe` | 仅 4px 高、无标高 | 管线钉死在容器中间 |
| 3 | `.tank-top-nozzle` | `top: 7px` 罐顶嘴 | **无管接入**，成装饰 |
| 4 | `.tank-outlet` | 罐底嘴 | 下一段管仍在中线，**从罐腰穿过** |
| 5 | `.tank-assembly::before/::after` | `top: 158px` 左右侧块 | 读成**罐腰进/出水口**——正是你说的「入水口也在中间」 |
| 6 | 阀/泵卡片 | 矮盒 center | 跟着管腰，强化错误读法 |

**一句话**：工艺应「**顶进底出、级间落下再抬升**」，实现却是「**所有节点穿竖向中线**」。

（图上已有 loop-wires / SP 标 / flow-ribbon / driver-badge，保留，只需挂在正确几何上。）

### C2 目标几何

```text
高位管 H1：P101 → FV101 ══╗（抬升后入罐）
                         ▼
                    ┌ 顶嘴 ┐
                    │  T1  │
                    └ 底嘴 ┘
                         │
低位管 L1：            FV102（两罐间低位）──► T2 顶
                    T1 底 ─┘

同理：T2 底 → FV103 → T3 顶；T3 底 → FV104 → 排水池
```

**硬规则**：入水只进顶、出水只出底、阀在管上、不在罐腰开工艺口。

### C3 布局方案（推荐 A）

**方案 A · 正交管廊（推荐）**

- 上标高 H1：给水与各罐**入口**水平段  
- 下标高 L1：各罐**出口**与级间/出口阀  
- 中间：罐设备带  
- 短竖管 + 弯头连接顶嘴/底嘴  
- FV101 在 H1；FV102/103/104 在 L1  

**方案 B · 小改（可先做）**

- 管改为 `align-items: flex-end` 贴罐底  
- 每罐左侧短管**上翻接入顶嘴**  
- **删除罐腰 `::before/::after` 法兰**  
- 阀挂在低位管  

**方案 C · 示意 P&ID**：明确 IN/OUT 标签，适合小屏投影，拟真度低。

### C4 显示层（几何修好后）

| 优先级 | 项 |
|--------|-----|
| P0 | 去掉罐腰法兰误读；顶嘴/底嘴与管中心对齐（CSS 变量 `--pipe-y-in/out`） |
| P0 | 阀中心落在所属管标高 |
| P1 | 流量标签只放水平管；SP 标与液位同一 % 映射 |

### C5 尺寸建议（在现网 314px 罐高基础上）

### C6 仿真图验收

1. 能指出顶进、底出，且与管相连  
2. FV102/103 在两罐之间管上，不在罐腰

4. 缩放 80%–180% 仍可读  
5. 空跑/暂停/评分有图上状态
