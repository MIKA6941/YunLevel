# 控制工作台与参数滑块验证说明

本文记录本次控制页 UI 改动的使用方式、自动验证入口和浏览器验收项。已有的内核、会话、评分和部署流程继续参考[交接须知](交接须知的注意文件.md)；本页用于补充本次 UI 验证。

## 界面与操作

- 左侧“回路”页以紧凑列表展示已搭建的单回路和串级；点击一项后，在仿真图下方的工作台编辑该回路。PID 计算过程也只显示所选回路，可通过“显示 PID”和“隐藏计算”切换。
- 左侧“手操”页保留当前模型的手操输入与“应用手操”操作。已被回路占用的执行器继续按原规则禁用。
- “搭建回路”与顶部“工程 / 方案”使用折叠区域，展开后可使用原有添加、保存、恢复、上传、下载和导入操作。
- 未应用的参数草稿保留在原表单中。仅切换选中回路，或接收回路结构不变的 SSE 状态更新，不会丢失草稿；实时 PV 和运行状态仍会刷新。增删回路、切换模型、恢复工程或退出登录不属于这项草稿保留保证。
- 点击可编辑数值可打开参数滑块。滑块和原输入双向同步：拖动修改原输入，在原输入中键入数值也会更新滑块。仍可直接键入数值。
- `Ti` 支持关闭积分：关闭状态使用 `inf`，`Ti=0` 仍为非法值。滑块与文字输入应保持同一关闭状态。
- 滑块只修改输入草稿；回路参数仍需点击“应用参数”，手操仍需点击“应用手操”才生效。
- `readonly` 或 `disabled` 输入不弹出滑块。与核心权限修复合并验收时，学生只读 SP 和教师观察窗口的禁用输入应保持这一行为。

## 自动验证入口

Windows 使用 PowerShell 7：`C:\Program Files\PowerShell\7\pwsh.exe`，脚本使用 UTF-8。进入仓库根目录后执行：

```powershell
npm run check
if ($LASTEXITCODE -ne 0) { throw 'JavaScript syntax check failed' }
npm run test:controls
if ($LASTEXITCODE -ne 0) { throw 'Control workspace tests failed' }
```

Linux 同样从仓库根目录执行 `npm run check` 和 `npm run test:controls`。

`npm run test:controls` 统一调用 `scripts/test-controls.js`。Runner 使用当前 Node 可执行文件，依次执行：

1. `public/app.js`、`public/control-workspace.js`、`public/parameter-slider.js` 的 `node --check`。
2. `node --test scripts/control-workspace.test.js scripts/parameter-slider.test.js`。

任一步失败即返回非零退出码。该入口只使用 Node 内置模块，不需要安装依赖、启动仿真服务或连接测试/生产服务器。测试数量以当前输出为准。

GitHub Actions 的 `.github/workflows/control-workspace.yml` 在 PR、向 `main` 推送及手动触发时运行，环境为 Ubuntu、Node 24；依次执行 `npm run check` 和 `npm run test:controls`。这两项覆盖语法、选择状态和滑块逻辑；DOM 交互与布局按下面的浏览器清单验收。完整发布仍需完成项目既有的 HX 自测和 E2E 回归。

## 浏览器验收清单

在隔离的本地测试实例中，分别检查 `tank` 和 `hx` 的学生、教师控制页面。使用桌面宽度、1201–1280px 断点区间和窄屏；核对浏览器控制台没有新增错误。

- [ ] 左侧回路列表切换正确；下方只显示选中回路表单，显示 PID 时计算内容与选择一致。
- [ ] 在回路 A 输入尚未应用的参数，切到 B 后再回 A，草稿不变；运行中等待 SSE 更新后重复这一检查。
- [ ] 未修改输入可随服务器状态同步，PV、手动/自动状态和列表读数持续刷新。
- [ ] 删除前面的回路后，原选择随同一回路移动；删除当前选择后，工作台显示一个仍存在的回路；清空后显示空状态。
- [ ] 两模型的回路选择互不干扰；退出后重新登录不继承上一会话的选择或回路草稿。
- [ ] “回路 / 手操”切换、搭建回路折叠、工程方案折叠可以用鼠标和键盘操作；原按钮仍完成对应操作。
- [ ] 点击可编辑数值打开滑块，拖动后原输入立即变化；原输入键入后滑块同步，输入值和显示值一致。
- [ ] 滑块不会在拖动时发送参数命令；点击相应的应用按钮后服务器状态才改变。
- [ ] `Ti` 有限值、关闭积分与直接输入 `inf` 状态一致，`Ti=0` 仍被拒绝。
- [ ] 回路占用的手操、学生只读 SP、教师观察窗口禁用输入均不能弹出滑块；权限恢复后只允许可编辑输入使用滑块。
- [ ] 隐藏/显示 PID、展开全部测量值、缩放及全屏仿真图不遮挡工作台控件；窄屏滑块和应用按钮可操作。
