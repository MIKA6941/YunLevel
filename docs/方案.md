# 仿真难度提升方案（多套）

> 范围：`tank` 三级液位、`hx` 换热器  
> 性质：**设计稿**，未改代码；供教学/考试分档选用  
> 日期：2026-09-25

---

## 0. 目标

在不破坏「仿真可跑、三门禁可过」的前提下，让控制从「调调 P 就稳」变成：

1. 要会抗扰与整定  
2. 要会处理约束与安全  
3. 要会选结构（单回路 / 串级）  
4. 要会管能效与操作代价  

---

## 1. 总览：难度维度

| 维度 | 液位 tank | 换热器 hx |
|------|-----------|-----------|
| 对象非线性 | 出流 √h、耦合 | 温度–流量–燃料耦合 |
| 执行器 | 泵/四阀 | 燃料阀、冷却阀、蒸汽 B 阀、HV1102 |
| 测量 | 三液位滞后/噪声 | TI1104、FI1105、壁温 |
| 扰动 | 出口阀、泵、SP | 蒸汽 B 负荷、HV1102 泄压、SP |
| 约束 | 液位安全窗、阀变率 | 超温/欠温、阀饱和、断冷却水 |
| 结构 | 单回路 / 串级 | 单回路 / 串级（TI→FI→FV1105） |
| 经济 | 出料/给水效率 | 产汽、燃料效率、HV1102 泄放损失 |

# A. 三级液位 tank — 五套方案

## 方案 T1 · 轻量抗扰（15 分钟课内）

**难度**：★☆☆☆☆  
**改动小，适合第一次实验。**

| 项 | 设置 |
|----|------|
| 测量噪声 | 开，±0.5%FS |
| 阀死区 | ±1% |
| 扰动 | 一次固定：FV104 −15%（T+6 min） |
| SP | 50/50/50 → 末段 60/55/50 |
| 评分 | 尾段目标 40 + 控制 35 + 操作 25 − 安全扣 |

**学生要会**：看噪声下是否阀抖；改 Td/Kp；一次扰动恢复。

---

## 方案 T2 · 随机工况（推荐默认考试档）

**难度**：★★☆☆☆

| 项 | 设置 |
|----|------|
| 噪声 | 开 |
| 阀死区 + 不对称变率 | 开阀 3%/s、关阀 2%/s |
| 泵压 | ±8% 随机游走（T=120s 相关） |
| 扰动 | **两段随机**：T+5min 与 T+12min，FV104 或泵 ±10~20%，幅度随机 |
| SP | 固定 50/50/50 |
| 安全窗 | 15–85% 内才算控制分；出窗扣安全 |

**学生要会**：不可预知扰动；不能只记「60 秒后调什么」。

**可复现**：扰动用种子 `seed`，考卷上写死 seed，保证每人同一剧本但事先不知。

---

## 方案 T3 · 耦合与可达域

**难度**：★★★☆☆

| 项 | 设置 |
|----|------|
| SP | **80 / 25 / 60**（已知不可达，需调 FV104） |
| 或 | 70 / 35 / 55 + FV104 限制 ≤40% |
| 阀特性 | 级间阀 Kv 非线性（开度平方近似） |
| 扰动 | SP 中段阶跃 T2 +20% |
| 评分 | 目标范围为主；**FV104 操作合理性**进操作分 |

**学生要会**：先判断可达域，再调阀位与 SP，而不是狂拧 Kp。

---

## 方案 T4 · 串级必做 / 结构对比

**难度**：★★★☆☆

| 项 | 设置 |
|----|------|
| 单回路 | 可跑，但系统分上限受限（如 max 75） |
| 串级 | LI（主）→ FI101（副）→ FV101，系统分可满 |
| 扰动 | 泵压 ±15%（考内环） |
| 评分 | 控制分 20：**必须有串级且副环跟踪**才拿满 |

**学生要会**：为何串级抗进水扰动；主副环时间尺度。

---

## 方案 T5 · 故障注入 / 竞赛档

**难度**：★★★★☆

| 故障（可配置） | 现象 | 期望 |
|----------------|------|------|
| FV104 卡滞 | 40% 不动 3 min | 换策略/用其它阀 |
| LI102 慢 8s | 测量滞后增大 | 减 D、降增益 |
| LI101 偏置 +2% | 测量偏高 | 用积分/交叉校验 |
| 泵失效 50% | 出力掉一半 | 重设 SP 或降负荷 |
| 动作次数限制 | 全程阀动作 ≤N 次 | 减少猛调 |

**评分**：安全 20 + 恢复 10 + 能耗 10；故障是否被识别进操作分（选做）。

# B. 换热器 hx — 五套方案

> 评分仍以 **过热蒸汽 B（FI1105）** 为主；HV1102 为蒸汽 A 泄压，参与难度与安全。

## 方案 H1 · 基础整定（对应现有推荐模板）

**难度**：★☆☆☆☆

- TI1104 → FV1102 冷却水，SP=450℃  
- 固定小扰动：FV1105 +10%  
- 考核：尾段带内、MAE、超调  

**适合**：第一次认识换热器对象。

---

## 方案 H2 · 蒸汽 B 负荷跟踪（推荐）

**难度**：★★☆☆☆

| 项 | 设置 |
|----|------|
| 负荷 | FI1105 给定 **斜坡或阶跃** 21→28→21 kg/s |
| 控制 | 仍以 TI1104±5℃ 为主；FI1105 跟给定 ±10% |
| 扰动 | 蒸汽 B 阀 FV1105 开度约束（最大 60%） |
| 收益 | 产汽 + 燃料效率（已在 v2） |
| 安全 | 超温/欠温倒扣 |

**学生要会**：负荷变化下温度不飞、不振。

---

## 方案 H3 · HV1102 泄压耦合（特色）

**难度**：★★★☆☆

| 项 | 设置 |
|----|------|
| 事件 | T+8min **HV1102 开 30–80%**（蒸汽 A 泄压） |
| 效应 | B 路流量/压力下降（已有耦合） |
| 要求 | TI1104 回 450±5℃，FI1105 回给定±10% |
| 评分 | **泄压期间 B 路跟踪** 单独 15 分；泄放损失进收益 |

**学生要会**：HV1102 与 FV1105 抢蒸汽，必须动 FV1102/FV1105 协调。

---

## 方案 H4 · 燃料与温度解耦

**难度**：★★★☆☆

| 项 | 设置 |
|----|------|
| 燃料 | 供油压力波动 → fuel_flow ±12% 随机 |
| 目标 | SP 450→480→460℃ 多段 |
| 结构 | 单回路难拿满；**串级 TI1104→FI1105→FV1105** 加分 |
| 收益 | 燃料单耗（kg/kg汽）排名进收益 |

**学生要会**：温度对象大滞后；燃料扰动与冷却阀分工。

---

## 方案 H5 · 故障 / 竞赛档

**难度**：★★★★☆

| 故障 | 现象 | 期望 |
|------|------|------|
| FV1102 卡滞 20% | 冷却水不动 | 用燃料/蒸汽阀救 |
| TI1104 慢 10s | 测量滞后大 | 降 D、松带宽 |
| FI1105 偏置 −2 kg/s | 流量显示偏低 | 靠温度间接判断 |
| HV1102 误开 50% | B 流量掉 | 恢复 FI1105 |
| 壁温超限 | twall 超阈值 | 安全倒扣 |

**评分**：安全倒扣加重；「故障期间不超温」进控制分。

# C. 评分如何配合难度

| 难度 | 控制/目标 | 操作 | 安全 | 收益 |
|------|-----------|------|------|------|
| 档 1 | 尾段带 40 + MAE | 25 | 倒扣 | 液位 0 / 换热 20 |
| 档 2 | 带 35 + 扰动恢复 15 | 20 | 倒扣加重 | 液位 0 / 换热 30 |
| 档 3 | 带 30 + 恢复 20 + 结构 10 | 15 | 倒扣 + 故障期 | **能耗/泄放** 10–15 |

**建议**：

- 液位：难度越高，**扰动与安全**占比越高；不设收益。  
- 换热：始终保留 **收益 25–30**；H3 把 **泄放损失** 算进收益。  
- 目标范围仍用 **尾段回推 0.35T**，防“前稳后飞”。
