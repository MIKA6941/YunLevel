> 对照：`docs/方案.md`（五套 tank + 五套 hx）  
> 方法：静态对照源码能力（不改代码、不跑改动回归）  
> 日期：2026-09-25

---

## 1. 验证结论（总表）

| 方案 | 可行性 | 现有可复用能力 | 主要缺口 | 建议 |
|------|--------|----------------|----------|------|
| T1 轻量抗扰 | **高** | 噪声字段、阀变率、扰动字段、评分倒扣 | 扰动脚本/UI 未接 | 可直接做 |
| T2 随机工况 | **高** | 同上 + 尾段目标 | 随机种子、泵波动未实现 | P0 推荐 |
| T3 耦合/可达域 | **高** | 阀位、SP、FV104 手操 | 非线性 Kv 未做 | 任务层即可 |
| T4 串级必做 | **中高** | 串级 API、副环字段 | 评分“强制串级”未做 | score 加规则 |
| T5 故障注入 | **中** | 阈值/扣分已有 | 卡滞/偏置/慢测未实现 | 需模型扩展 |
| H1 基础 | **高** | TI→FV1102、FI1105 | — | 已具备 |
| H2 负荷跟踪 | **高** | flow_setpoint、FV1105 | 任务脚本 | P0 |
| H3 HV1102 泄压 | **高** | **HV1102 + 耦合已实现** | 任务/评分挂钩 | P0 |
| H4 燃料解耦 | **中高** | fuel_flow、温度 ODE | 燃料扰动模型未做 | 小改 plant |
| H5 故障竞赛 | **中** | 超温/断水扣分 | 故障注入未做 | 需模型扩展 |

**总评**：**T1–T3、H1–H3 当前架构下可直接落地**；T4 为评分规则问题；T5/H5 需加故障模型。

## 3. 方案逐条可行性

### T1 / T2（噪声、死区、随机扰动）

| 项 | 可行 | 工作量 | 备注 |
|----|------|--------|------|
| 噪声 | 是 | 小 | `noise_enable` 已有；建议默认开或 UI 开关 |
| 阀死区 | 是 | 小 | rate_limit 后加死区 |
| 波动 | 是 | 小 | `q_pump` 或 `qin` 加随机游走 |
| 两段扰动 | 是 | 中 | **ScoreSetDisturb 存在但未推动阀门**；需在 SCORE_TICK/命令里改阀 |
| 固定种子 | 是 | 小 | `srand` / 持久 seed 字段 |

**结论**：**可做**；P0 只缺「扰动真正改阀」与噪声默认策略。

### T3 可达域（80/25/60 等）

| 项 | 可行 | 备注 |
|----|------|------|
| 任务层 SP + FV104 | 是 | 已实测不可达；调 FV104 可达 |
| 非线性 Kv | 可选 | Torricelli 已非线性；阀 Kv 平方可选 |

**结论**：**不改模型即可当考题**；加阀特性可再升档。

### T4 串级强制

| 项 | 可行 | 备注 |
|----|------|------|
| 串级运行 | 是 | 两模型均支持 |
| 评分检测串级 | 是 | `has_cascade` / nCasc 可用 |
| 控制分规则 | 待改 score | 只改评分，不改仿真 |

**结论**：**可行**，偏评分层。

### T5 / H5 故障注入

| 故障 | 可行性 | 缺口 |
|------|--------|------|
| 阀卡滞 | 中 | 需插件式 fault 状态 |
| 测量慢 | 低-中 | 改 TAU 即可 |
| 测量偏置 | 低-中 | meas+bias |
| 泵失效 | 中 | pump_gain |
| 动作次数限制 | 中 | score 计数即可 |

**结论**：**可做但为模型扩展**；建议放档 3，不阻塞 T2/H3。

### H1 / H2（蒸汽 B 负荷）

| 项 | 可行 | 备注 |
|----|------|------|
| 阶跃/斜坡 flow_setpoint | 是 | `flow_setpoint` 已有 |
| FV1105 上限 | 是 | SET_VALVE / fv1105_open_min |
| 评分绑 FI1105 | 是 | v2 已按蒸汽 B |

**结论**：**可直接出题**。

### H3 HV1102 泄压

| 项 | 可行 | 备注 |
|----|------|------|
| HV1102 阀 | **已实现** | MV=3 |
| 与 B 路耦合 | **已实现** | 流量/压力系数 |
| 流量可测 | 是 | `relieve` 字段 |
| 任务：定时开阀 | 是 | 命令 `SET_VALVE 3 x` |
| 评分：泄放损失 | 可选 | 收益加一项 |

**结论**：**可行性最高**，建议作为换热器核心加难点。

### H4 燃料解耦

| 项 | 可行 | 缺口 |
|----|------|------|
| fuel_flow 扰动 | 需小改 plant | 当前燃料较稳 |
| 多段 SP | 是 | setpoint 命令 |

**结论**：可行，工作量小～中。

## 4. 风险与回归

| 风险 | 说明 | 缓解 |
|------|------|------|
| 扰动改阀破坏“仿真正常” | 误驱动回路阀 | 只动未占用阀/手操阀 |
| 噪声导致 smoket 脆弱 | MAE 判据 | 门禁固定种子、噪声可关 |
| 故障改动力学 | 破坏 selftest | 故障默认关；回归关故障 |
| 评分与难度耦合 | 复杂 | 难度档用配置开关，不改主路径 |

**门禁**：任何实施后仍需 `check + selftest_hx + smoke-e2e`；扰动/故障用固定 seed 可复现。

---

## 5. 推荐落地顺序（可行性视角）

1. **P0（高可行）**：噪声开关 + 阀死区 + T2 两段扰动（真正改阀）  
2. **P0**：H2 负荷阶跃任务 + **H3 HV1102 泄压事件**（物理已备）  
3. **P1**：安全窗/能耗分、T4 串级加分规则  
4. **P2**：H4 燃料扰动、T5/H5 故障注入  

---

## 6. 一句话

**T1–T3、H1–H3 用现有模型即可或只差任务脚本；HV1102 与评分 B 路已就绪。**  
**T5/H5 才需要改 plant 加故障；实施时默认关故障、三门禁回归。**
