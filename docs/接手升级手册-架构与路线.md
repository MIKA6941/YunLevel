## 1. 工程一句话

**云仿真教学平台**：浏览器多人做过程控制实验；每个学生独立内核进程；教师管班、看状态、评成绩。  
当前 **双实验模型**：

| modelId | 名称 | 内核 | 典型工艺 |
|---------|------|------|----------|
| `tank`（默认） | 三级液位 | `YunEngine`（`native/`） | 三罐串联 + PID/串级/评分 |
| `hx` | 换热器 | `HxEngine`（`native-hx/`） | E1102 + 炉膛/燃料/给水/蒸汽 + 温度/流量控制 |

同目录桌面版 `TankLevelPID.exe` / 根目录源码为 **单机教学/评分版**，与云版共享物理/PID 思路，但代码树分离；升级以 **YunLevel** 为主。

## 2. 架构地图

```text
Browser (public/index.html + app.js + styles.css)
        │  HTTP + SSE
Node 网关 (server/server.js)
        │  子进程 stdin/stdout 文本命令
YunEngine | HxEngine  (native / native-hx)
        │
data/  按 model 隔离：state|history|submissions|teacher_backups
       换热器为 hx-state / hx-history / hx-submissions / hx-teacher_backups
```

| 层 | 目录 | 职责 | 红线 |
|----|------|------|------|
| D1 物理内核 | `native/` `native-hx/` | 模型积分、PID、评分 | 模型分支只允许在这里 |
| D2 P&ID | `public/app.js` 渲染器段 + CSS/HTML | tank 罐图 / hx E1102 图 | 模型分支只允许在这里 |
| D3 ModelSpec | `server/models.js` + 前端描述符 | 位号、历史字段、目录、会话键 | 模型分支只允许在这里 |
| 平台 | `server/*` 登录/会话/SSE/班级/云端 | **禁止** `if (modelId==='hx')` 散落 | 液位行为零回归 |
| 前端平台 | `public/app.js` 大部分 | 控制卡、曲线、评分、教师 UI | 差异走描述符 |

**铁律（必须继承）**

1. 液位侧 `sessionKey`、数据目录名、状态魔数 `YLV1`、`HISTORY_FIELDS` **不得改**  
2. 换热器魔数 `YLHX`，与液位互不恢复  
3. PID：`Ki = 1/Ti`；`Ti=∞` 关积分；`Ti=0` 非法  
4. 改动前门禁：`npm run check` + `selftest_hx` + `scripts/smoke-e2e.js` 三绿

## 6. 接手工作方式

1. **改前**：读相关 `docs/*` 与本手册；跑三门禁；有疑先查 `换热器融合方案设计` 红线。  
2. **改中**：液位零回归优先；模型差异只进 D1/D2/D3。  
3. **改后**：`check` + `selftest_hx` + `smoke-e2e` + 手动点选关键路径；更新 `项目进度.md`。  
4. **测试资产**：可将临时矩阵脚本收编为 `scripts/regression-*.js`（仍建议）。
