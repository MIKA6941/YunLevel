# 测试轮次记录

本目录每完成一轮测试，放一份记录。**只增不改**。

## 命名

```
测试-YYYYMMDD-第NN轮.md
```

- `NN` 全局递增，从 `01` 起，永不复用
- 同日多轮：`测试-20260928-第01轮.md`、`测试-20260928-第02轮.md`

## 填写方法

1. 复制 `模板.md`，改名
2. 全部字段都要填，不适用的写「不适用」并说明原因，**不要留空**
3. 冒烟测试的 `failures` 明细要**原样粘贴**，不要转述
4. 人工体验的 12 个问题记**原话**，不要改写成书面语
5. 结束后归档源码快照 + sha256，并把路径填进记录
