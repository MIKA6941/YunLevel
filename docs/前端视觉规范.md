# 教学实验工作台视觉规范

保留 YunLevel 深色教学界面，用清晰读数和稳定的操作层级帮助搭建回路与整定 PID。原生 HTML/CSS/JS，无新增字体、图标或运行依赖。

| 项目 | 约定 |
| --- | --- |
| 背景 / 面板 | `#0E151D` / `#16222E` |
| 主文字 / 次文字 | `#EDF3F8` / `#A9BBCB` |
| 主操作 | `#33CDA6`，用于启动、应用及选中状态 |
| 字号 | 正文 14px，标签至少 12px，常驻读数 22px |
| 数字 | 等宽数字对齐，单位随测量值显示 |
| 圆角 | 面板 12px，控件 8px |
| 间距 | 4 / 8 / 12 / 16 / 24px，组内紧凑、组间留白 |

控制操作集中在顶部；回路选择与手操位于左栏，仿真图居中，选中回路参数位于右栏。1440px 起使用三栏，900–1439px 将参数栏移至图下，900px 以下按照 DOM 顺序纵向排列。折叠工程方案、搭建工具、全部检测值及 PID 计算，保留常用动作和关键读数。

颜色之外同时提供文字状态：未应用、应用中、已应用、失败、只读、禁用。输入支持直接填写和滑块，应用按钮明确下发；请求失败或回复较晚时保留未提交草稿。可编辑字段具有可见键盘焦点；原生下拉框沿用深色模式，响应减少动画偏好。

关键测量值和回路 PV 从当前模型的 SSE 状态读取，缺值显示“—”。绘图缩放后设备标注可能变小，图下常驻读数始终保持固定字号，可通过放大、适配和全屏查看工艺结构。

曲线、评分及教师管理页继承通用控件、色彩和焦点样式，结构保持现有版本。权限和评分规则由服务器决定，本规范不增加命令或修改规则。
