## 1. 实施摘要

| 模块 | 改动 |
|------|------|
| `native/config.h` | 限时：单对象 480 s / 系统 1500 s；尾段回推比 0.35 |
| `native/score.h/.cpp` | 操作分步（无搭建分）；尾段目标 ρ_tail；安全倒扣；液位收益=0；系统扰动字段预留 |
| `native-hx/hx_score.*` | 操作 20 + 目标/控制 + 收益 30；安全倒扣；本期无扰动 |
| `native/engine.cpp` / `engine-hx.cpp` | score JSON 增加 `target`、`safetyDeduction`、`durationS`；按模式输出单对象/系统分 |
| `server/engine-session.js` | summary 透出 `target`、`safetyDeduction`、`durationS` |
| `public/app.js` | 评分页：未开始/已结束可进（进行中锁定）；显示目标范围分；开始评分 confirm |

**分值结构（实现口径）**

| 模式 | 毛分 | 安全 |
|------|------|------|
| 液位单对象 | 操作≤25 + 目标≤40 + 控制≤35，收益 0 | 倒扣 |
| 换热单对象 | 操作≤20 + 目标≤30 + 控制≤20 + 收益≤30 | 倒扣 |
| 系统 | 操作/目标/扰动(液位)/收益按上述对齐 | 倒扣 |
