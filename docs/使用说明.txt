三级液位 PID 云仿真  使用说明
================================

【当前版本说明（2026-09-25 复核）】
本说明是较早的课堂入门文档，仍然适合了解登录、控制、曲线和评分的基本流程。
当前云版已经增加换热器模型、模型开放开关、双模型教师看板、云端方案和新的
保存/恢复规则；双模型细节请以 docs/学生端功能手册.txt、docs/教师端功能手册.txt、
docs/交接须知的注意文件.md 为准。

一、这套系统是什么
--------------------------------
这是桌面版「三级液位 PID 仿真」的服务器版本。老师把程序部署在一台服务器上之后，
同学们用浏览器打开同一个网址，各自登录、各自实验，互不影响：

  * 每个人在服务器上拥有一个独立的仿真进程；
  * 你的回路、PID 参数、曲线、评分都只属于你自己；
  * 关掉浏览器不会丢数据，下次登录会接着上次的状态（但是恢复为「未启动」，需要重新点启动）；
  * 评分由服务器上的仿真内核计算，浏览器不能改分。

系统只有一个总教师账号。老师登录后可以直接进入控制 / 仿真、曲线和评分页面做课堂演示，也可以管理全部班级的名单，查看各班在线状态、曲线和评分记录，
并按班级筛选、导出 CSV。学生不设个人密码，只需输入所属班级码、学号和姓名。
教师演示使用独立会话，不计入学生在线列表，也不会写入学生评分记录。


二、学生怎么用
--------------------------------
1. 打开老师给的网址（例如 https://pid.xxx.com 或 http://服务器IP:8080）。
2. 选择「学生登录」，填写：
     班级码  老师发给本班的班级码
     学号    本班名单中的学号
     姓名    必须和名单中的姓名完全一致
3. 点「进入仿真」。

学生端有三个页签：控制 / 仿真、曲线、评分。教师端同样可以使用这三个页签进行教学演示，并额外拥有教师看板和班级管理。
两个班可以使用相同的学号，不会互相顶掉；同一班级内重复登录同一学号时，后登录者会顶掉前一个会话。


三、控制区
--------------------------------
控制区左边是操作面板，右边是仿真画面，最下面是 PID 计算过程。

操作按钮
    启动          开始推进仿真（按下后仿真时间开始走）
    暂停          暂停/继续
    回到冷态      把液位、阀门、评分全部复位成冷态（评分必须在冷态才能切换）
    推荐工况      一键搭好老师预设的回路和参数
    高分模板      一键套用高分参考模板（单回路 / 串级各一套）

单回路 / 串级 切换
    只能在冷态（未启动）时切换。运行中不允许切换，以免回路和参数混在一起。

手操
    P101 泵开度、FV101～FV104 手操值，改完之后点「应用手操」生效。
    有回路自动控制的阀门会由 PID 接管，手操值只在没有回路驱动该阀门时起作用。

前馈偏置
    「前馈偏置：关 / 开」按钮，默认关闭。打开后 PID 输出会叠加给水前馈偏置，
    用于抵消泵和管路带来的静态偏差。

搭建回路
    回路类型选「单回路」：选择被控量（LI101/LI102/LI103 液位，或 FI101/FI102/FI103 流量）
    和阀门，点「添加」。
    回路类型选「串级」：选择阀门、主环、副环，点「添加」，即得到「主环 + 副环」的串级回路。
    同一个阀门不能被两个回路同时控制（系统会阻止重复搭建并提示）。

回路卡片
    每张卡片对应一个回路，可以改 SP、Kp、Ti、Td、手动输出，点「应用参数」生效。
    Ti 填 inf 表示不投入积分（即 Ti 趋于无穷大，Ki = 1/Ti 趋于 0）。
    正作用 / 反作用按钮可以切换控制方向：
      正作用：PV 高于 SP 时开大阀门（适合被控量随阀门开大而上升的场合）；
      反作用：PV 高于 SP 时关小阀门（适合液位这类"进水多则液位高"的场合）。
    如果发现"液位为 0 时阀门不动、必须改成正作用才动"，说明这个回路的 PV→MV 方向判断反了，
    按反作用重新设置即可（三级液位里的液位回路通常用反作用）。

PID 计算过程
    只有在添加了回路之后才会显示内容；没有回路时显示「暂未添加回路」。
    每条回路显示：偏差 e = SP - PV、P / I / D 三项、偏置、以及输出 u(t)。
    串级回路同时显示主环和副环的计算过程。


四、仿真画面
--------------------------------
仿真区按工艺顺序排列：P101 泵 → FV101 → 1#罐 → FV102 → 2#罐 → FV103 → 3#罐 → FV104。
每个罐体里的液位高度实时变化，阀门节点在开度大于 0 时高亮。

下方一栏是各检测点的实时数值：
    LI101 / LI102 / LI103  罐内液位，单位 %（满量程 0～100%）
    FI101 / FI102 / FI103  给水流量、级间流量，单位 L/min
    出口流量                FV104 后排出的流量
    PI101                  泵出口压力，单位 kPa


五、曲线
--------------------------------
曲线页分成三张图，彼此独立：

    液位曲线    LI101～LI103 与对应 SP，纵轴固定 0～100% 液位（不再用 mm）
    流量曲线    FI101 / FI102 / FI103 / 出口流量，纵轴 L/min
    开度曲线    P101 / FV101～FV104，纵轴 0～100% 开度

图例按钮就是显隐开关：点一下隐藏该条曲线，再点一下显示。
流量曲线的「Y 上限」可以自己填数值，留空则自动缩放。
液位曲线纵轴固定 0～100%FS，方便直接看偏差和超调。


六、评分
--------------------------------
评分只能在冷态切换方案。步骤：

1. 点「回到冷态」，确认仿真未启动。
2. 在控制区或评分页选择评分方案：
       关闭评分    不评分
       单罐评分    只评一个罐（下面可以选 LI101 / LI102 / LI103）
       系统评分    评整个三级系统
3. 点「开始评分」。系统会：
       * 清空当前的回路卡片；
       * 把仿真复位到冷态；
       * 从 0 开始计时（评分时间显示在评分页）。
4. 自己搭建回路、整定 PID、把液位稳定到 SP。
5. 评分限时 30 分钟，时间一到自动结束，页面显示「评分结束」并在结果画面显示评分结束时间；
   此时才能查看评分记录，老师端也会收到一条评分记录。

评分维度（单罐与系统满分都是 100 分）：
    操作得分   是否规范搭建回路、是否投入自动
    控制得分   稳态误差、超调、稳态时间
    安全得分   低限/高限时间、溢流、抽空
    收益得分   流量平衡、给水利用率、外送水量

详细的扣分细则见同目录的《评分说明.txt》。


七、教师端
--------------------------------
使用总教师入口登录（口令由服务器环境变量 YUN_TEACHER_CODE 决定）：
登录后默认进入控制 / 仿真，可和学生在同一套界面上启动、搭回路、调 PID、看曲线和评分。
教师的仿真状态独立保存，但不会出现在学生在线列表，也不会占用学生评分记录。

班级管理
  新建班级       填写班级名称和班级码，班级码只能使用 2～32 位字母、数字、下划线或短横线
  班级列表       显示每个班的启用学生数/学生总数；选择后可修改班级设置或删除班级
  添加学生       输入学号和姓名，保存后立即生效
  逐行修改       可改学号、姓名、启用状态；停用或删除后，该学生当前会话会停止
  批量导入       支持 .xlsx、.xls、.csv，也可手动粘贴“学号,姓名”；合并导入保留原名单，覆盖导入会先完整校验再替换
  导出名单       导出当前班级的学生名单 CSV

教师看板
  在线学生   学号、姓名、班级、运行状态、三个罐的液位、回路数、当前评分，可点「查看曲线」
  班级筛选   只查看指定班级，评分记录和导出也随筛选变化
  学生详情   选中学生的液位与 SP 曲线
  评分记录   所有已完成的评分，可按班级筛选、导出或清空记录

看板每隔一秒自动刷新一次。学生退出后，状态栏会显示为不在线。


八、常见问题
--------------------------------
Q: 刷新页面后仿真停了？
A: 这是有意设计的：恢复状态时统一恢复为「未启动」，避免无人看管时仿真继续跑。点「启动」继续即可。

Q: 换了电脑/浏览器还能接着做吗？
A: 可以。用同样的学号姓名重新登录，服务器会把上次的参数和回路恢复出来（状态为未启动）。

Q: 两个班有相同学号会怎样？
A: 不同班级之间完全隔离，可以正常同时登录。只有同一个班级内使用相同学号时，
   后登录者才会顶掉前一个会话。

Q: 为什么 FV101 只开一点点，流量就和 FV102/FV103 全开差不多？
A: FV101 由泵提供压头，FV102/FV103 靠上一级罐的液位重力压头。罐高约 300 mm 时
   FV102/FV103 全开约 6.95 L/min，而 FV101 只需要约 35% 开度就能通过同样的流量。
   这是压头和稳态物料平衡的结果，不是阀门参数写错了。

Q: 同一液位控制两个阀门，改 SP 会不会被覆盖？
A: 不会。SP 只在发生修改时同步一次，之后不会实时覆盖你手填的数值。

Q: 评分中途回到冷态会怎样？
A: 评分会话结束，成绩按当前数据封存，可以在评分结果画面查看。

Q: 页面提示「当前在线人数已达服务器上限」？
A: 服务器设置了最大同时在线人数，请联系老师调整。


九、给老师的提示
--------------------------------
* 系统只有一个总教师账号。班级名称、班级码和名单都在「班级管理」页面维护，改完立即生效。
* 总教师口令和最大在线人数在服务器上的 docker-compose.yml 里配置，改完执行
  docker compose up -d 生效；YUN_CLASS_CODE 只在首次建立空班级时使用。
* 班级名单保存在 data/classes.json，不要手工改文件；系统会在正式启动前先备份。
* 评分记录文件在服务器的 YunLevel/data/score_records.jsonl，删除记录建议用教师页面的
  「清空记录」按钮，避免手工改文件。
* 上课前建议先自己登录跑一遍，确认服务器时间、网络和带宽正常。
