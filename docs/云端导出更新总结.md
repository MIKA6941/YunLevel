# 三级液位 PID 云版 云端导出更新总结

> **文档状态：历史更新总结（2026-09-22），2026-09-25 复核。**  
> 本文记录那一轮的导出改造，不是当前完整功能说明。  
> 当前双模型导出、教师数据查看和云端方案口径，请以 `docs/交接须知的注意文件.md`、`docs/项目进度.md`、教师端功能手册为准。

更新日期：2026-09-22

## 一、本次更新目标

本次更新把学生数据导出统一收口到教师端，并固定使用学生主动上传到云端的方案 1。教师批量导出时不再读取学生当前在线状态，也不再临时从实时曲线生成图片。

学生端继续保持“上传云端”作为课堂数据提交入口；原来的参数、曲线和工程导出相关代码不删除、不覆盖，仅隐藏当前不使用的入口。

## 二、学生端更新

1. 学生端不提供参数导出。
2. 学生端不提供曲线图片导出。
3. 学生端不提供工程导出。
4. 学生旧参数、曲线、工程导出接口返回 403。
5. 学生点击“上传云端”时，同时上传：
   - 当前仿真状态；
   - 回路与 PID 参数快照；
   - 当前曲线视图状态；
   - 液位曲线 PNG；
   - 流量曲线 PNG；
   - 开度曲线 PNG。
6. 云端方案 1 在下拉框中显示为“下载云端（方案 1）”，底层仍使用 `slot-1`。
7. 上传仍要求仿真已暂停，并且教师已开放学生上传权限。

## 三、教师端更新

1. 教师看板增加按班级选择学生的云端数据列表。
2. 支持勾选一名或多名学生。
3. 支持“全选本班”和“取消选择”。
4. 支持“导出云端 ZIP”。
5. 教师导出只读取学生已上传的云端方案 1。
6. 教师导出不读取学生在线状态。
7. 教师导出不从学生实时曲线临时生成图片。
8. 未上传、旧版上传缺少参数或图片的学生，会在 ZIP 中标记“请学生重新上传”。

教师导出 ZIP 结构：

```text
班级_云端导出_时间戳.zip
├─ 班级参数汇总.csv
├─ 导出清单.csv
├─ 导出说明.txt
└─ students/
   └─ 001_学号_姓名/
      ├─ 参数.csv
      ├─ 液位曲线.png
      ├─ 流量曲线.png
      ├─ 开度曲线.png
      └─ 导出状态.txt
```

## 四、服务端与存储更新

1. 云端方案 1 新增保存以下文件：
   - `state.bin`
   - `history.json`
   - `meta.json`
   - `params.json`
   - `curve-view.json`
   - `images/level.png`
   - `images/flow.png`
   - `images/valve.png`
2. `meta.json` 增加参数、曲线视图和图片完整性状态。
3. PNG 上传增加格式签名校验。
4. 单张 PNG 最大 4 MB。
5. 云端上传请求体上限调整为 24 MB，避免三张 Base64 图片超过原 12 MB 限制。
6. 新增教师批量导出接口：
   - `POST /api/teacher/cloud-export`
7. 学生旧导出接口保持存在，但拒绝学生调用：
   - `/api/current/export`
   - `/api/projects/:slot/export`

## 五、保留但当前停用的功能

以下功能的数据和实现代码保留，当前不使用或隐藏入口，后续需要时可以恢复：

- 学生端参数导出；
- 学生端曲线图片导出；
- 学生端工程导出；
- 教师端在线学生参数导出；
- 教师端实时曲线图片导出；
- 教师查看在线学生和实时曲线的相关逻辑。

本次没有删除这些代码，也没有让教师云端导出改回读取在线状态。
