## 4. 仿真图 / UI 修改建议（含参考图 E1102）

结合参考 P&ID 图与当前 `hxProcessVisual`（炉膛 + E1102 + 三阀 + 读数条）给出方向。

### 4.1 当前实现优点

- 已有：F101 炉膛、E1102 壳与管束/汽包、液位填充、SP/Δ、三阀角标、流动 ribbon、循环接线 `hxLoopWires`、读数面板  
- 位号齐全：TI1103/1104、FI1105、FV1101/1102/1105、燃料/给水/蒸汽流量  

### 4.2 参考图暴露的通病（避免做成那样）

| 参考图问题 | 建议 |
|------------|------|
| 大圆盘设备语义不清 | E1102 保持「壳 + 管束 + 汽包」，标题已较清楚，可再加强管内侧/壳程箭头 |
| 管在中线“穿”设备 | 换热器：**燃料侧进炉膛、给水进汽包/管束、蒸汽出右侧**，接口短管插进壳内 |
| 标注悬空 | TI/FI/FV 用 **圆泡+引线** 锚在管心 |
| 阀过小 | FV110x 加大 + 开度条，与 % 同色系 |
| 构图空、KPI 弱 | 换热量/壁温/出口温度 **顶栏 KPI**，不要只挤在角上 |
| 流向不清 | 每段管单向箭头；红=烟气/蒸汽热侧，蓝/灰=水侧 |

### 4.3 建议布局（hx）

```text
[燃料 F101] ──FV1101──►  炉膛(燃烧/热源) ──热烟►  ┐
                                                    ▼
[给水] ──FV1102──►  汽包/管束 E1102  ──► 蒸汽 FV1105 ──► 出口 FI1105
                         │ TI1104 · SP · Δ
                         └ 汽包液位
顶部 KPI: TI1104 | SP | Δ | FI1105 | 换热 kW | 壁温
```

| 标高 | 内容 |
|------|------|
| 上 | 烟气/热侧：炉膛 → E1102 |
| 中 | E1102 主设备（略右），左侧给水，右侧蒸汽 |
| 下 | 仪表与次要读数；或顶栏 KPI |

### 4.4 显示优化清单

| 优先级 | 项 | 说明 |
|--------|-----|------|
| P0 | **进出口正交、短管入壳** | 消除“管穿设备/贴中线” |

| P2 | 暂停/评分水印 | 与液位模型一致 |

### 4.5 文案与操作（与测试结果对齐）
